## 3. Agent Operating Doctrine & Proactive Suggestion Rules

Whenever the user asks for guidance, code modifications, or strategy:

1. **Check State Legal Restrictions First**: Always verify 50-state Prepayment Penalty (PPP) laws before recommending loan structures (e.g., FL/TX allow 5-year stepdown; MN, PA, NJ, KS, NM have strict threshold or entity limits).
2. **Apply AEGIS Structuring Hacks**:
   - If DSCR < 1.20x: Suggest Interest-Only (I/O) to lower debt service.
   - If LTV > 75%: Suggest a 1.0 point rate buydown to lower PITI.
   - If Short-Term Rental: Recommend AirDNA / Rabbu 100th percentile market report verification.
3. **Use CQR Certainty Scoring**: Evaluate deals against cash flow volatility, ARM rate reset shock, and liquidity reserve depth.
4. **Proactive Guidance**: Do not wait for the user to ask about edge cases. Proactively suggest optimizations based on the research blueprints whenever working in the repo.
