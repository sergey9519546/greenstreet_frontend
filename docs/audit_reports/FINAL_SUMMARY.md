## ⚠️ **POST-DEPLOYMENT: 1 MANUAL TASK**

After deployment completes (you'll get a URL), you MUST:

### **Add Environment Variables to Vercel**

1. Go to: https://vercel.com/dashboard
2. Select: greenstreet-frontend project
3. Settings → Environment Variables → Add:

```
VITE_FIREBASE_API_KEY=<your_key>
VITE_FIREBASE_AUTH_DOMAIN=<your_domain>
VITE_FIREBASE_PROJECT_ID=<your_project>
VITE_FIREBASE_STORAGE_BUCKET=<your_bucket>
VITE_FIREBASE_MESSAGING_SENDER_ID=<your_sender_id>
VITE_FIREBASE_APP_ID=<your_app_id>
ANTHROPIC_AUTH_TOKEN=<optional_ai_key>
```

4. Save variables
5. Trigger redeploy: `vercel --prod`

**Without these variables, Firebase features won't work.**
