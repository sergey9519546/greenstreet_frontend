## 1. LLC vs Personal Name for DSCR Loans

### Overview

DSCR loans are unique because they qualify based on property cash flow rather than personal income. This creates a strategic choice: borrow in your personal name or through an LLC entity. The decision affects liability protection, tax treatment, lender options, and long-term portfolio strategy.

### Borrowing in Personal Name

| Factor | Details |
|--------|---------|
| **Eligibility** | Available at all DSCR lenders; no entity formation required |
| **Asset Protection** | None — personal assets exposed to property-related lawsuits |
| **Title Transfer** | Property titled directly to individual; can transfer to LLC later (may trigger due-on-sale) |
| **Rate Impact** | Slightly lower rates at some lenders (0.125–0.25% lower) because individuals are seen as simpler underwriting |
| **Closing Speed** | Faster — no entity document review, no EIN wait, no state filing delay |
| **Insurance** | Personal hazard insurance; no commercial policy needed |
| **Foreclosure Risk** | Personal liability on note; deficiency judgment can attach to personal assets |
| **Refinance Flexibility** | Can refinance into conventional/FHA if desired later |
| **Tax Reporting** | Schedule E on personal return; simpler but less segregating |
| **Portfolio Scaling** | Difficult — each property adds personal liability exposure |

### Borrowing Through an LLC

| Factor | Details |
|--------|---------|
| **Eligibility** | Accepted by most DSCR lenders; some require it |
| **Asset Protection** | Strong — LLC creates liability shield; only LLC assets at risk |
| **Title Transfer** | Property titled directly to LLC at closing; clean chain of title |
| **Rate Impact** | Slightly higher rates (0.125–0.375% premium) at some lenders; many price identically |
| **Closing Speed** | 3–10 extra days for entity verification, EIN, good standing certificates |
| **Insurance** | Commercial hazard policy required; often $200–500/yr more expensive |
| **Foreclosure Risk** | Recourse limited to LLC; personal assets generally protected (unless personal guarantee) |
| **Refinance Flexibility** | Cannot refinance into conventional/FHA in LLC name; must transfer out first |
| **Tax Reporting** | Separate partnership/corporate return; can elect pass-through or S-Corp status |
| **Portfolio Scaling** | Ideal — each LLC isolates risk; separate Series LLC cells for multiple properties |

### Lenders That Require LLC for DSCR Loans

| Lender | LLC Required? | Notes |
|--------|--------------|-------|
| **Visio Lending** | Required in GA, HI, IL, MA, NJ, NY, PA, VA | State-specific due to title/foreclosure law |
| **LendingOne** | Preferred, not required | 0.25% rate discount for LLC vesting |
| **Kiavi** | Not required | Accepts both; recommends LLC for asset protection |
| **Limelight** | Not required | Accepts individual and entity |
| **CoreVest** | Required | All loans must be in entity name |
| **RidgeLend** | Not required | Accepts both |
| **First Lien** | Preferred | Slight rate preference for LLC |
| **Visio** | Conditional | See Section 9 for state-specific rules |
| **Gravity Lending** | Not required | Accepts both |
| **Global Integrity** | Required | Entity only for all DSCR products |

### Key Pros/Cons Summary

**Pros of LLC:**
- Liability isolation per property
- Easier to add partners/investors
- Cleaner bookkeeping for multiple properties
- Professional appearance for portfolio growth
- Some lenders offer better terms for entity borrowers
- Estate planning benefits (transfer membership interests)

**Cons of LLC:**
- Formation and maintenance costs ($100–$500/yr)
- Separate tax returns ($500–$1,500/yr for CPA)
- Slightly higher rates at some lenders
- Commercial insurance costs more
- Cannot access conventional/FHA products
- More complex closing process
- Ongoing state compliance (annual reports, registered agent)

## 2. Series LLC & DSCR Lending

### What Is a Series LLC?

A Series LLC is a specialized LLC structure where a "master" LLC creates separate "series" (or "cells"), each with its own members, managers, assets, and liabilities. Each series operates as a distinct entity for liability purposes while sharing one master filing with the state.

### How Series LLC Works for Real Estate

```
Master LLC (filed with state)
├── Series A — 123 Main St Rental (Property #1)
├── Series B — 456 Oak Ave Rental (Property #2)
├── Series C — 789 Pine Dr Rental (Property #3)
└── Series D — Future acquisition
```

Each series has:
- Its own bank account
- Its own operating agreement
- Its own members/ownership structure
- Its own assets and liabilities
- Liability isolation from other series

### DSCR Lender Acceptance of Series LLC

| Lender | Accepts Series LLC? | Conditions |
|--------|---------------------|------------|
| **Visio Lending** | Yes (case-by-case) | Each series treated as separate borrower; requires separate operating agreement per series |
| **LendingOne** | Yes | Must provide certificate of designation for each series |
| **Kiavi** | No (as of 2024) | Requires standard single-member or multi-member LLC |
| **CoreVest** | Case-by-case | Prefers individual LLCs per property |
| **Limelight** | No | Standard LLC only |
| **First Lien** | Case-by-case | Requires legal opinion on series asset segregation |
| **RidgeLend** | No | Standard LLC preferred |
| **Gravity Lending** | Case-by-case | Must demonstrate series is properly formed and maintained |

### Advantages of Series LLC for DSCR Investors

| Advantage | Details |
|-----------|---------|
| **Cost efficiency** | One state filing fee instead of multiple LLC formations; saves $100–$500 per additional property |
| **Ongoing maintenance** | One annual report/fee instead of multiple; significant savings at scale |
| **Liability isolation** | Each series shields other series from its liabilities (if properly maintained) |
| **Flexible ownership** | Different members/percentages per series |
| **Administrative simplicity** | One EIN, one registered agent, one state filing |
| **Scalability** | Add new series via internal operating agreement amendment — no state filing needed |

### Risks and Limitations

| Risk | Details |
|------|---------|
| **Uncertain liability protection** | Case law is still developing; courts in some states haven't fully tested series-level liability shields |
| **Lender skepticism** | Many DSCR lenders won't accept series LLCs, limiting options |
| **Inter-series liability** | If master LLC is sued and series aren't properly segregated, assets across series may be at risk |
| **Banking complications** | Some banks won't open separate accounts per series; may commingle funds |
| **State recognition gaps** | Non-series-LLC states may not recognize series-level liability protection |
| **Tax complexity** | Each series may need separate tax treatment; IRS guidance is evolving |
| **Operating agreement requirements** | Must have airtight series-specific operating agreements; generic templates are dangerous |

### Best Practices for Series LLC with DSCR Loans

1. **Form in a series LLC state** (DE, IL, NV, TX, etc.) even if property is elsewhere
2. **Maintain strict segregation** — separate bank accounts, separate books, no commingling
3. **Get a legal opinion letter** from an attorney confirming series-level liability protection
4. **Prepare series-specific operating agreements** — don't rely on the master agreement alone
5. **Confirm lender acceptance** before committing to a series LLC structure
6. **Register as foreign LLC** in the property state if required
7. **Maintain separate insurance** per series/property

## 3. Land Trust & DSCR Mortgages

### What Is a Land Trust?

A land trust is a legal arrangement where a trustee holds legal title to real property for the benefit of a beneficiary (the investor). The beneficiary retains all economic benefits — rental income, appreciation, tax deductions — while the trustee holds title.

### How Land Trusts Work for Investment Property

```
Investor (Beneficiary) → Appoints → Trustee (holds legal title)
                                  → Property titled in trust name
                                  → "ABC Land Trust, John Doe as Trustee"
Investor retains:
  - Power of direction over trustee
  - Right to income and proceeds
  - Right to sell/encumber property
  - Tax benefits
```

### DSCR Lender Acceptance of Land Trust Vesting

| Lender | Allows Land Trust? | Conditions |
|--------|-------------------|------------|
| **Visio Lending** | Yes (some programs) | Must provide trust agreement; beneficiary must guarantee |
| **LendingOne** | No | Requires individual or LLC vesting only |
| **Kiavi** | Case-by-case | Requires review of trust documents; beneficiary must be borrower |
| **CoreVest** | Generally no | Prefers LLC or individual |
| **Limelight** | No | Standard entity or individual only |
| **First Lien** | Case-by-case | Must provide complete trust documentation |
| **RidgeLend** | No | Does not accept land trust vesting |
| **Gravity Lending** | Case-by-case | Trust must be revocable; beneficiary must be borrower |

### Advantages of Land Trust for DSCR Properties

| Advantage | Details |
|-----------|---------|
| **Privacy** | Property records show trustee name, not beneficiary; prevents public linkage to investor |
| **Avoids probate** | Beneficiary interest passes per trust terms, not through probate |
| **Assignment flexibility** | Beneficial interest can be assigned without recording deed (no transfer tax in many states) |
| **Due-on-sale protection** | Garn-St. Germain Act exempts transfers into revocable land trusts from due-on-sale clauses |
| **Simplified succession** | Successor beneficiary takes over seamlessly upon death/incapacity |
| **Liability perception** | Some attorneys argue land trust interest is personal property, not real property — harder for judgment creditors to force sale |

### Disadvantages of Land Trust

| Disadvantage | Details |
|--------------|---------|
| **Limited lender acceptance** | Most DSCR lenders won't lend to land trusts; significantly narrows options |
| **No asset protection** | Land trust provides privacy, NOT liability protection — a common misconception |
| **Complexity at closing** | Trust documentation review adds time and legal cost |
| **Insurance complications** | Must name trust as insured; some insurers resist |
| **Refinance constraints** | Many conventional and DSCR lenders won't refinance a property in a land trust |
| **State variation** | Land trust law varies significantly; IL and FL have strongest statutory frameworks |
| **Partnership difficulty** | Harder to have multiple beneficiaries with different interests |
| **No charging order protection** | Unlike LLCs, land trusts don't offer charging order protection for creditors |

### Key Distinction: Land Trust ≠ Asset Protection

> **Critical**: A land trust is a **privacy tool**, not a liability shield. If a tenant sues and wins, the judgment can reach the beneficiary's interest. For actual asset protection, combine land trust with LLC: LLC is the beneficiary of the land trust.

### Recommended Structure: Land Trust + LLC

```
Property → Titled to → Land Trust (trustee holds title)
                        ↓ Beneficiary
                        LLC (owned by investor)
                        ↓
                        Investor
```

This provides:
- **Privacy** from land trust (public records show only trustee)
- **Liability protection** from LLC (lawsuits stop at LLC)
- **DSCR loan compatibility** (loan to LLC; property in land trust where lender allows)

## 4. S-Corp Rental Property & DSCR Loans

### Can an S-Corp Get a DSCR Loan?

**Short answer**: It's possible but uncommon and often disadvantageous. Most DSCR lenders prefer LLCs or individuals. S-Corps introduce complications that make DSCR lending more difficult.

### S-Corp Eligibility for DSCR Loans

| Lender | Accepts S-Corp? | Notes |
|--------|----------------|-------|
| **Visio Lending** | No | LLC or individual only |
| **LendingOne** | Case-by-case | Requires additional corporate documentation |
| **Kiavi** | Generally no | Prefers LLC or individual |
| **CoreVest** | Possibly | Requires extensive entity review |
| **Limelight** | No | LLC or individual only |
| **First Lien** | Case-by-case | Requires K-1 history and corporate docs |
| **Most others** | Rarely | S-Corp is not a standard DSCR borrowing entity |

### Why S-Corps Are Problematic for DSCR Lending

| Issue | Details |
|-------|---------|
| **Reasonable compensation requirement** | S-Corp owners who materially participate must take a "reasonable salary" (subject to FICA taxes) — undermines the self-employment tax savings for rental income |
| **Passive vs active** | Rental income is generally passive; IRS doesn't allow S-Corp rental activities to avoid SE tax unless the S-Corp provides significant services (hotel-like operations) |
| **DSCR underwriting complexity** | DSCR lenders calculate coverage from property cash flow; S-Corp tax returns (1120S) commingle multiple income streams, making it harder to isolate property-level DSCR |
| **Lender unfamiliarity** | DSCR underwriting teams are trained on LLC (1065/Schedule E) and individual (Schedule E) borrowers; S-Corp is an edge case |
| **Transfer restrictions** | S-Corp ownership is limited to 100 shareholders, one class of stock, US residents only — limits flexibility |
| **Built-in gains tax** | Converting property from S-Corp to another structure can trigger built-in gains tax |
| **QBI deduction uncertainty** | Whether rental income through an S-Corp qualifies for the Section 199A QBI deduction is complex and fact-dependent |

### S-Corp vs LLC for Rental Properties — Tax Comparison

| Factor | LLC (Default/Partnership) | S-Corp |
|--------|--------------------------|--------|
| **Self-employment tax** | Rental income generally NOT subject to SE tax | Same — rental income generally NOT subject to SE tax |
| **Reasonable salary required** | No | Yes, if owner is also an employee (but rental income ≠ salary) |
| **Tax filing** | 1065 (partnership) or Schedule C (SMLLC) | 1120S |
| **QBI deduction (Sec 199A)** | May qualify depending on income | Same; no inherent advantage |
| **Payroll requirement** | None | Must run payroll if owner works in the business |
| **Fringe benefits** | Limited | More options (health insurance, retirement plans) |
| **Asset protection** | Strong (charging order protection) | Corporate veil; but personal service = risk |
| **Estate planning** | Flexible membership interests | Stock transfer restrictions |
| **DSCR lender acceptance** | Widely accepted | Rarely accepted |

### When S-Corp Might Make Sense for Real Estate

1. **Active real estate business** — property management company, flipping operation, or short-term rental business with significant services
2. **High-income investors** — those who need the reasonable salary structure for other income streams and want the S-Corp umbrella
3. **Employer benefits** — accessing S-Corp fringe benefits like health insurance and retirement plans for employees
4. **Existing S-Corp** — property already held in S-Corp and transfer costs are prohibitive

### Bottom Line

> For pure rental property DSCR loans, **S-Corp is almost never the right choice**. Form an LLC instead. If you have tax reasons to consider S-Corp, elect S-Corp status for your LLC (IRS Form 2553) — this gives you S-Corp tax treatment while maintaining LLC entity structure, which is more DSCR-lender-friendly.

## 5. Best State to Form LLC for Real Estate: DE vs WY vs NV

### The Three Dominant Choices

Investors commonly consider Delaware, Wyoming, and Nevada for LLC formation due to their business-friendly laws. However, for real estate specifically, the calculus is different than for tech startups.

### Delaware (DE)

| Factor | Details |
|--------|---------|
| **Filing fee** | $90 |
| **Annual franchise tax** | $300 |
| **State income tax** | None on LLC (pass-through) |
| **Court system** | Court of Chancery — specialized business court; most sophisticated case law |
| **Asset protection** | Strong charging order protection; no creditor pierce-through |
| **Series LLC** | Yes — authorized since 2004 |
| **Privacy** | Member names not required on public filing |
| **Operating agreement flexibility** | Extremely flexible; default rules favor LLC managers |
| **Best for** | Large portfolios, institutional investors, complex multi-member structures |
| **Drawback for real estate** | If property is in another state, must register as foreign LLC there anyway — eliminates most DE advantage |

### Wyoming (WY)

| Factor | Details |
|--------|---------|
| **Filing fee** | $100 |
| **Annual report/fee** | $60 (minimum) or $0.0002 per asset value |
| **State income tax** | None — no state income tax at all |
| **Court system** | Business-friendly but small; less case law than DE |
| **Asset protection** | Excellent — Wyoming pioneered the LLC; strongest charging order protection in the US |
| **Series LLC** | No — Wyoming does NOT authorize series LLCs as of 2025 |
| **Privacy** | Excellent — member/manager names NOT on public records |
| **Lifetime trust provision** | Unique — WY allows perpetual LLCs and dynasty trusts |
| **Best for** | Single-property investors, cost-conscious investors, maximum privacy |
| **Drawback** | No series LLC option; small state court system |

### Nevada (NV)

| Factor | Details |
|--------|---------|
| **Filing fee** | $425 |
| **Annual list/fee** | $350 |
| **State income tax** | None — no state income tax |
| **Court system** | Business court established; growing case law |
| **Asset protection** | Excellent — charging order protection; no information sharing with IRS |
| **Series LLC** | Yes — authorized since 2005 |
| **Privacy** | Good — member names not required on initial filing but on annual list |
| **No IRS information sharing** | Unique — NV does not share LLC information with the IRS |
| **Best for** | Privacy-focused investors, investors wanting IRS non-sharing, series LLC in western US |
| **Drawback** | Highest costs ($425 + $350/yr); cost-prohibitive for small portfolios |

### Head-to-Head Comparison

| Feature | Delaware | Wyoming | Nevada |
|---------|----------|---------|--------|
| **Formation cost** | $90 | $100 | $425 |
| **Annual cost** | $300 | $60 | $350 |
| **5-year total cost** | $1,590 | $400 | $2,175 |
| **No state income tax** | No (but LLC pass-through) | Yes | Yes |
| **Charging order protection** | Excellent | Best in US | Excellent |
| **Series LLC** | Yes | No | Yes |
| **Privacy** | Good | Excellent | Good |
| **Court sophistication** | Best in US | Adequate | Good |
| **Registered agent req.** | Yes ($50–200/yr) | Yes ($50–125/yr) | Yes ($125–250/yr) |
| **Real estate specific advantage** | Low | Medium | Low |

### The Home State Rule — Why It Often Trumps the "Best State" Debate

> **Critical insight**: If your rental property is in State X, you generally must register your DE/WY/NV LLC as a "foreign LLC" in State X. This means:
> - You pay State X's foreign registration fee ($100–$500)
> - You pay State X's annual report/fee
> - You comply with State X's laws for the property
> - You now have **two states** of compliance
>
> **For single-state properties**, it's often simplest and cheapest to form the LLC in the property's state. The DE/WY/NV advantage is strongest for:
> - Multi-state portfolios (one LLC holding properties in multiple states)
> - Investors who don't own the property yet (entity ready for acquisitions)
> - Investors who prioritize privacy and asset protection over cost

## 6. Foreign LLC Registration for Rental Properties

### What Is Foreign LLC Registration?

When an LLC formed in one state (the "domestic" state) does business in another state, it must register as a "foreign LLC" in that second state. For real estate, owning rental property almost always qualifies as "doing business" in the property's state.

### When Is Foreign Registration Required?

| Activity | Foreign Registration Required? |
|----------|-------------------------------|
| Own rental property in State B | **Yes** — virtually all states consider this "doing business" |
| Manage rental property remotely | **Yes** — the property location triggers it |
| Flip property in State B | **Yes** — active business activity |
| Hold vacant land in State B | **Usually yes** — ownership alone can trigger it |
| Lend money secured by property in State B | **Often yes** — depends on state |
| Own property via Series LLC cell | **Yes** — each cell's property state requires registration |

### Consequences of Not Registering

| Consequence | Details |
|-------------|---------|
| **Cannot sue in state court** | LLC cannot bring lawsuit in the property's state until registered |
| **Penalties and back fees** | Most states impose late fees ($100–$1,000+) |
| **Personal liability risk** | Some states may hold members personally liable for LLC obligations |
| **Contract enforcement risk** | Lease agreements and other contracts may be unenforceable |
| **No effect on LLC existence** | Failure to register does NOT dissolve the LLC — but it limits legal rights |
| **Lender issues** | DSCR lenders will verify good standing; unregistered LLC = no closing |

### Multi-State Compliance Strategy

```
Option A: Home State LLC + Foreign Registrations
  Form LLC in WY → Register as foreign in FL, TX, GA, NC
  Pros: One entity, one operating agreement, centralized management
  Cons: Multiple state filings, cumulative fees

Option B: Separate LLC Per State
  Form LLC-FL in Florida → owns FL properties
  Form LLC-TX in Texas → owns TX properties
  Form LLC-GA in Georgia → owns GA properties
  Pros: No foreign registration needed; state-specific customization
  Cons: Multiple entities, multiple operating agreements, more admin

Option C: Series LLC (where available)
  Form Series LLC in DE or NV
  Series A → holds FL property (register foreign in FL)
  Series B → holds TX property (register foreign in TX)
  Pros: One master filing; per-series isolation
  Cons: Foreign registration still needed per state; series acceptance varies
```

### Registered Agent Requirements

Every foreign (and domestic) LLC must have a registered agent in each state where it's registered. Options:

| Option | Annual Cost | Pros | Cons |
|--------|------------|------|------|
| **Professional RA service** | $50–$300/yr per state | Reliable, compliance-focused, forwards legal mail | Adds $100–$600/yr per state |
| **Attorney as RA** | $100–$500/yr per state | Legal guidance included | Most expensive option |
| **Self as RA** | $0 | Free | Must have physical address in state; process served at your address; privacy loss |
| **Boilerplate RA (e.g., NW Registered Agent)** | $125/yr per state | National coverage, privacy, scanning | Additional cost per state |

## 9. Visio Lending: LLC-Required States Explained

### Which States Require LLC and Why

Visio Lending — one of the largest DSCR lenders — requires LLC vesting in the following states:

| State | LLC Required? | Reason |
|-------|--------------|--------|
| **Georgia (GA)** | Yes | State law restricts foreclosure rights for individual borrowers; LLC vesting ensures clean non-judicial foreclosure path |
| **Hawaii (HI)** | Yes | Complex foreclosure laws; LLC provides cleaner title and foreclosure process |
| **Illinois (IL)** | Yes | Illinois foreclosure process (judicial) is significantly simpler for entity borrowers; individual borrowers have extensive redemption rights |
| **Massachusetts (MA)** | Yes | MA title theory state; strict foreclosure rules for individuals; entity vesting streamlines process |
| **New Jersey (NJ)** | Yes | NJ has some of the most borrower-friendly foreclosure laws in the US; judicial foreclosure takes 12–18 months for individuals; entity vesting allows faster remedies |
| **New York (NY)** | Yes | NY foreclosure process for individuals is extremely slow (avg 18–36 months); entity vesting provides more streamlined remedies |
| **Pennsylvania (PA)** | Yes | PA judicial foreclosure process is protracted for individual borrowers; LLC vesting accelerates the process |
| **Virginia (VA)** | Yes | VA requires entity vesting for non-owner-occupied investment properties under certain loan programs |

### Why These States Specifically?

The common thread across these states:

1. **Judicial foreclosure states** — All require court-supervised foreclosure, which is slow and expensive
2. **Borrower-friendly redemption rights** — These states give individual borrowers extensive rights to cure defaults
3. **Deficiency judgment limitations** — Individual borrowers in these states often enjoy anti-deficiency protections
4. **Title theory complications** — Some are title theory states where the mortgage creates a lien theory issue
5. **Consumer protection laws** — State consumer lending laws often protect individual borrowers but not business entities

By requiring LLC vesting, Visio:
- Removes the borrower from consumer protection statutes
- Streamlines the foreclosure/remedy process
- Reduces the time and cost of default resolution
- Makes the loan more attractive to downstream investors/securitizers

### What This Means for Investors

If you're buying in GA, HI, IL, MA, NJ, NY, PA, or VA:
- **You must form an LLC** before closing with Visio (or find a different lender)
- Factor in LLC formation time (3–10 business days) in your closing timeline
- Budget for LLC formation and annual maintenance costs
- Consider forming the LLC in the property's state to avoid foreign registration

## 10. Trust Ownership & DSCR Mortgages

### Overview

Trusts can hold real estate, but DSCR lenders have varying policies about lending to trusts. The two main categories are revocable trusts (living trusts) and irrevocable trusts.

### Revocable (Living) Trust

| Factor | Details |
|--------|---------|
| **Definition** | Trust created during grantor's lifetime; grantor retains control and can revoke/modify |
| **Grantor is typically trustee** | Grantor manages assets as trustee |
| **Tax treatment** | Pass-through to grantor's personal return; no separate trust tax return needed (if grantor is trustee) |
| **Asset protection** | **None** — revocable trust assets are considered grantor's assets for creditor purposes |
| **Probate avoidance** | Yes — primary benefit; assets pass outside probate |
| **DSCR lender acceptance** | More widely accepted than irrevocable trusts, but still limited |
| **Rate impact** | Usually same rate as individual if beneficiary = borrower |
| **Due-on-sale** | Garn-St. Germain Act exempts transfers to revocable trusts from due-on-sale clauses (12 USC § 1701j-3) |

### Irrevocable Trust

| Factor | Details |
|--------|---------|
| **Definition** | Trust that cannot be revoked or modified by grantor once created |
| **Grantor relinquishes control** | Independent trustee manages assets |
| **Tax treatment** | Separate tax entity; files Form 1041; may have compressed tax brackets |
| **Asset protection** | **Strong** — assets generally beyond reach of grantor's creditors |
| **Estate tax benefits** | Removes assets from grantor's taxable estate |
| **DSCR lender acceptance** | Rarely accepted; very few DSCR lenders will lend to irrevocable trusts |
| **Rate impact** | Higher rates if accepted (0.25–0.50% premium) |
| **Due-on-sale** | Transfer to irrevocable trust may trigger due-on-sale clause; no Garn-St. Germain exemption |

### DSCR Lender Trust Policies

| Lender | Revocable Trust | Irrevocable Trust | Conditions |
|--------|----------------|-------------------|------------|
| **Visio Lending** | Case-by-case | No | Trust must be revocable; beneficiary must guarantee |
| **Kiavi** | Case-by-case | No | Trust documentation required; beneficiary = borrower |
| **LendingOne** | No | No | LLC or individual only |
| **CoreVest** | Case-by-case | Case-by-case | Requires full trust review; typically requires LLC beneficiary |
| **Limelight** | No | No | Individual or LLC only |
| **First Lien** | Case-by-case | No | Revocable only; beneficiary must be borrower |
| **RidgeLend** | No | No | Individual or LLC only |
| **Gravity Lending** | Case-by-case | No | Revocable only; limited acceptance |

### Trust + LLC Combined Structure (Recommended)

The most effective structure for DSCR investors who want trust benefits:

```
Option A: LLC Beneficiary of Trust
  Property → Titled to → Revocable Living Trust
                          ↓ Beneficiary
                          LLC (owned by investor)
                          ↓ Member
                          Investor

  Pros: Probate avoidance (trust) + liability protection (LLC)
  Cons: Complexity; some lenders won't accept this structure

Option B: Trust Owns LLC
  Investor → Creates → Revocable Living Trust
                       ↓ Owns 100%
                       LLC (holds property)
                       ↓ Titled to
                       Property

  Pros: Clean ownership chain; LLC borrows the DSCR loan; trust owns LLC
  Cons: Must ensure trust is revocable and investor controls both

Option C: TOD Transfer on Death (Simplest)
  Property → Titled to → LLC
                       + TOD designation to trust/heirs

  Pros: Simple; avoids probate; LLC borrows DSCR loan
  Cons: TOD may not cover all scenarios; state law varies
```

### When to Use Trusts for DSCR Properties

| Scenario | Recommended Structure |
|----------|----------------------|
| **Single investor, 1–3 properties** | LLC with TOD designation (avoids trust complexity) |
| **Married couple, growing portfolio** | Revocable living trust owns LLC membership interests |
| **Estate planning focus** | Irrevocable trust → LLC → property (rare for DSCR; usually conventional) |
| **Privacy priority** | Land trust → LLC → investor |
| **Multi-generational** | Dynasty trust (WY/South Dakota) → LLC → property |
| **Asset protection priority** | LLC → property; use insurance for additional protection |

### Key Warnings

1. **Never transfer a property into an irrevocable trust without lender approval** — this can trigger the due-on-sale clause and accelerate the loan
2. **Trusts don't provide liability protection** — only LLCs/corporations do (revocable trusts = no protection; irrevocable = grantor protection only)
3. **DSCR lenders are increasingly LLC-friendly** — if you have an LLC, most trust benefits can be achieved through the LLC's operating agreement (succession provisions)
4. **Trust tax rates are compressed** — irrevocable trusts hit the top tax bracket (37%) at just $14,450 of income (2024), making them tax-inefficient for high-rent properties
5. **Always coordinate with legal counsel** — trust/LLC combinations require careful drafting to avoid unintended consequences

## 12. Decision Framework & Recommendations

### Step-by-Step Entity Selection Process

```
Step 1: Check Lender Requirements
  → Does your DSCR lender require LLC? (Visio in 8 states, CoreVest always)
  → Does your lender accept your preferred entity type?
  → Any rate differences by entity type?

Step 2: Assess Your Portfolio Scale
  → 1 property → SMLLC in property state
  → 2-4 properties, same state → Separate SMLLCs or Series LLC
  → 5+ properties → Series LLC or separate LLCs per "risk group"
  → Multi-state → Series LLC with foreign registrations or separate state LLCs

Step 3: Evaluate State-Specific Factors
  → Property state's LLC formation cost
  → Property state's annual fees
  → Does property state authorize series LLC?
  → Does property state have franchise/income tax?
  → Does property state have strong charging order protection?

Step 4: Consider Tax Implications
  → State income tax on LLC income
  → Franchise tax obligations
  → QBI deduction eligibility
  → S-Corp election consideration (rare for pure rentals)

Step 5: Factor in Privacy Needs
  → Do you want your name off public records?
  → Consider land trust for privacy layer
  → Use registered agent service for address privacy

Step 6: Plan for Growth
  → Will you add properties? In which states?
  → Will you add partners?
  → Will you need to refinance into conventional products?
  → Estate planning considerations?
```

### Top 5 Recommendations for DSCR Investors

| Rank | Recommendation | Rationale |
|------|---------------|-----------|
| **1** | **Always use an LLC for DSCR properties** | Asset protection is non-negotiable for investment properties; individual vesting exposes all personal assets |
| **2** | **Form LLC in the property's state for single-state investments** | Avoids foreign registration costs and complexity; simpler compliance |
| **3** | **Use Series LLC for 5+ properties** | Dramatic cost savings on formation and maintenance; liability isolation per series |
| **4** | **Add land trust layer for privacy** | Land trust as title holder + LLC as beneficiary = privacy + protection |

### Common Mistakes to Avoid

| Mistake | Consequence | Fix |
|---------|-------------|-----|
| Forming LLC in DE/WY for property in another state without foreign registration | Cannot enforce contracts; penalties; lender won't close | Register as foreign LLC in property state |
| Using individual vesting for a portfolio of 5+ properties | Cumulative liability exposure; one lawsuit reaches all assets | LLC per property or series LLC |
| Assuming land trust provides liability protection | Lawsuit reaches beneficiary directly | Use land trust + LLC combination |
| S-Corp election for passive rental income | No SE tax savings; reasonable salary requirement; DSCR lender rejection | Keep default LLC taxation; S-Corp only for active real estate businesses |
| Not maintaining LLC formalities | Piercing the corporate veil; personal liability | Separate bank accounts, annual meetings, proper documentation |
| Transferring property to LLC after closing without lender consent | Due-on-sale clause acceleration; loan called due | Notify lender; most DSCR lenders allow transfer; get consent first |
| Using one LLC for all properties | One lawsuit exposes all properties | One LLC per property or series LLC with separate cells |
| Forgetting annual reports/fees | LLC administratively dissolved; loss of liability protection | Calendar reminders; use compliance service or registered agent notifications |
