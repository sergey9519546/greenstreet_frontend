# Glossary — Decoder Ring

## Acronyms / Terms

| Term | Meaning |
|------|---------|
| DSCR | Debt Service Coverage Ratio — rent ÷ PITIA; core qualifying metric |
| PITIA | Principal, Interest, Taxes, Insurance, Association (HOA) — full monthly housing payment |
| ITIA | Interest, Taxes, Insurance, Association — IO-loan denominator (no principal) |
| Non-QM | Non-Qualified Mortgage — loans outside CFPB QM safe harbor |
| LTV / CLTV | Loan-to-Value / Combined LTV |
| PPP | Prepayment Penalty |
| IO | Interest-Only |
| STR | Short-Term Rental |
| BRRRR | Buy, Rehab, Rent, Refinance, Repeat |
| Track 1 / Track 2 | Dual-track DSCR: T1 = lender qualification (rent/PITIA); T2 = investor survival (after vacancy/OpEx) |
| Sovereign Engine v11 | Pure-TypeScript deterministic DSCR engine, 22 modules, zero runtime deps |
| Golden Vectors | Pinned canonical test values for engine parity (ANALYSIS/GOLDEN_VECTORS.md) |
| LLPA | Loan-Level Price Adjustment |
| Magic Buckets | Categorical encodings (LTV/DSCR/FICO/reserves buckets) for the ML model |
