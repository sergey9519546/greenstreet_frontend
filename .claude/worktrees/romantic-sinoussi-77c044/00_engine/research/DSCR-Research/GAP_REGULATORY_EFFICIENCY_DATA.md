### 1.4 FL Save Our Homes — Investor Impact (CRITICAL)

**Save Our Homes (SOH) applies ONLY to homestead properties.** Key details:

- **Homestead**: Assessed value capped at 3% annual increase OR CPI, whichever is less
- **Non-homestead (investors)**: 10% annual cap on assessment increases (Amendment 5, 2008)
- **Portability**: Homestead owners can transfer up to $500K of SOH benefit to new FL home — **investors cannot**
- **At sale**: Property reassessed to full market value regardless
- **Practical impact**: A $300K investor property in Miami-Dade could see assessment jump from $250K to $300K in one year (20% increase vs 10% cap = capped at 10%, but still $25K increase in assessed value)
- **Tax bill difference**: Investor pays ~$300-600/yr MORE than identical homestead property due to higher assessment

### 5.2 How State Income Tax Applies to Rental Income

**Rule: Income is taxed where the PROPERTY is located (sourcing rule)**

- Rental income from a property in CA → taxed by CA at CA rates, even if investor lives in TX
- This is called **"source income"** — the state where the property sits has first claim
- Investor's HOME STATE may also tax the income, but typically offers a credit for taxes paid to the source state
- **Exception**: If home state has no income tax (TX, FL, etc.), investor only pays source state tax

### 8.2 Scoring Methodology

Each factor scored 0-100, where **100 = most favorable to investor** (lowest cost/least restriction).

**Property Tax Score** = 100 × (1 - (state_rate - min_rate) / (max_rate - min_rate))
- min = 0.27% (AL), max = 2.33% (NJ)

**Insurance Score** = 100 × (1 - (state_premium - min_premium) / (max_premium - min_premium))
- min = $1,190 (AK), max = $7,785 (FL)

**Income Tax Score** = 100 if rate = 0%; else 100 × (1 - state_rate / 13.3%)

**Transfer Tax Score** = 100 × (1 - (state_transfer_on_350K - 0) / (max_transfer_on_350K))
- max = $10,773 (Philadelphia scenario) or $700 (NY state)

**Closing Cost Score** = 100 × (1 - (state_closing - min_closing) / (max_closing - min_closing))

**Entity Cost Score** = 100 × (1 - (state_year1_cost - min_year1) / (max_year1 - min_year1))

**Prepayment Score** = 100 if no restrictions; 75 if 3-yr limit; 50 if 2% cap; 25 if prohibited

**RES = 0.25×PropTax + 0.25×Insurance + 0.20×IncomeTax + 0.10×TransferTax + 0.10×ClosingCost + 0.05×Entity + 0.05×Prepay**

## APPENDIX C: IMPLEMENTATION NOTES FOR DSCR APEX ENGINE

### How to Use This Data in Pricing

1. **Property Tax**: Look up by state + county. Use effective rate × assessed value. For CA, use 1.25% assessment ratio × market value × local rate. For TX, use 100% market value × local rate.

2. **Insurance**: Base rate by state, then adjust for:
   - Coastal surcharge: +50-200% within 10 miles of coast
   - Flood zone: +$800-$4,500/yr for Zone AE
   - Wind/hail deductible: 1-5% of dwelling in coastal states
   - Age of roof: +30-50% if >15 years

3. **Transfer Tax**: State rate × purchase price + local surcharge. Always check county/city add-ons.

4. **Income Tax**: Apply to NET rental income after depreciation, expenses. State tax = (rental income - expenses) × state marginal rate.

5. **Entity Costs**: Annualize LLC costs; divide by number of properties if using series LLC.

6. **Prepayment**: Check if DSCR loan prepayment structure is legal in the property state. If not, add 25-50 bps to rate.
