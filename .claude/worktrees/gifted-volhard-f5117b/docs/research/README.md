# DSCR Research Index

This folder holds the consolidated research corpus that was previously scattered across the project root.

## Folders

- `specs/` - canonical product, engine, underwriting, and AEGIS specifications.
- `deep-dives/` - formula notes, rigorous research, architecture debt analysis, and recheck reports.
- `analysis/` - lender intelligence, business questions, market strategy, and gap analysis.
- `sprints/` - sprint research plans, execution notes, and phase reports.
- `ml-architecture/` - TimesFM and LoRA architecture work.
- `operational/` - command center, verification logs, unified hub, and next-step docs.
- `_archive/` - superseded drafts preserved for provenance.

## Cleanup Rule

Do not delete older research drafts until citations, Obsidian links, and index references have been reconciled. Archive superseded material first, delete only after a second pass confirms no unique content or metadata remains.
